# Сайт-визитка Ирины

## Ссылка для клиентов

`https://201325iki-hub.github.io/irina-ai/`

Эту ссылку можно отправлять в Telegram, ВКонтакте, WhatsApp, письмах и коммерческих предложениях.

## Как открыть на ноутбуке Windows

1. Скачайте итоговый архив `IRINA_site_card_final.zip`.
2. Откройте папку **Загрузки**.
3. Нажмите на архив правой кнопкой мыши.
4. Выберите **Извлечь всё** → **Извлечь**.
5. В открывшейся папке дважды нажмите `index.html`.
6. Если Windows спросит программу, выберите **Google Chrome** или **Microsoft Edge**.

Сайт откроется как одна длинная страница. Кнопки верхнего меню переводят к нужным блокам этой же страницы. В блоке услуг нажимайте стрелки **←** и **→** или круглые точки: они перелистывают страницы делового блокнота.

Интернет для демонстрации самого сайта не требуется: стили, сценарии, SVG-значки и портрет встроены в один файл. Интернет понадобится только при переходе в Telegram, ВКонтакте или электронную почту.

Файл `IRINA_site_card_interactive.html` — отдельная интерактивная версия для передачи клиентам. Файл `site-card.pdf` — трёхстраничная версия для просмотра и отправки предприятиям.

## Короткая воронка

Первый экран → перелистываемый деловой блокнот → три шага работы → связь с Ириной.

## Важно при последующем подключении сервисов

Перед подключением CRM, аналитики, внешних форм или файлов cookie необходимо обновить политику обработки данных под фактические сервисы.
