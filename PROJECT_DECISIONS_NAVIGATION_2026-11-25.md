# Утверждённое решение: навигация сайта Ирины

Дата подтверждения: 2026-11-25. Источник решения: прямое указание Ирины в рабочем чате.

## Утверждённые переходы

- Сайт-визитка: https://201325iki-hub.github.io/irina-ai/
- Сайт-визитка, действие «Посмотреть решения»: переход на лендинг https://201325iki-hub.github.io/irina-ai/solutions/
- Лендинг /solutions/, пункт «Обо мне»: переход **обратно на визитку** (../). Это правильный, специально утверждённый переход, НЕ ошибка.
- По утверждённой структуре отдельный блок «Обо мне» не должен добавляться на визитку; согласованный раздел о человеке относится к лендингу. Не менять размещение или содержание автоматически: сначала сверить с утверждённой версией и фактическим видом страниц.

## Ограничения

- Не предлагать менять двустороннюю навигацию. Не трактовать ссылку «Обо мне» на лендинге, которая ведёт на визитку, как ошибку.
- Не вводить новые разделы, не сокращать согласованные тексты и не изменять сайт только на основании обсуждения.
- Не считать исследование HTML-кода проверкой реального поведения браузера.
- Любые будущие правки — только после отдельного согласования и проверки страниц на ПК/телефоне.

Зафиксировано решение **без изменений HTML, настроек и публикации**. Локальная папка на диске D / VS Code этим коммитом не синхронизируется и не считается сохранённой. Источник состояния для совместной работы — этот файл в GitHub до настройки и проверки локальной синхронизации.
